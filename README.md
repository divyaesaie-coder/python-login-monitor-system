# Python Login Monitor System

A beginner-friendly Python project that monitors login activity using IP addresses.

## Features
- User login tracking
- IP address monitoring
- Suspicious login detection
- Login and logout simulation
- Menu-driven console application

## Technologies Used
- Python 3

## How It Works
The program:
1. Accepts login requests with IP address
2. Counts login attempts from each IP
3. Detects suspicious repeated logins
4. Allows logout simulation
5. Exits the application

## Concepts Used
- Lists
- Dictionaries
- Counters
- Loops
- if-else conditions
- User input handling
